# Life Tracker — Telegram Mini App

Личный трекер поверх существующего Google Sheets: финансы, тело, работа, привычки.
Быстрый ввод и дашборд с телефона, внутри Telegram.

Таблица остаётся source of truth — приложение только читает и пишет её строки.

---

## Как это устроено

```
Telegram Bot (aiogram)
    └── кнопка «Открыть трекер» → Mini App
Mini App (React + Tailwind, внутри Telegram WebView)
    └── HTTPS → Backend API
Backend (FastAPI)
    ├── проверяет подпись initData и сверяет user.id
    ├── читает/пишет Google Sheets (service account, gspread)
    └── считает все метрики сам, в Python
Google Sheets — хранилище (5 листов)
```

Бот и API живут в одном процессе (`backend/run.py`), поэтому на Railway нужен
один сервис. Собранный фронтенд отдаёт тот же FastAPI.

### Метрики считаются в коде

Дашборд не читает лист `Dashboard` и не зависит от формул в таблице: бэкенд
берёт сырые ячейки одним batch-запросом и агрегирует их сам. Формулы в самой
таблице остаются — они нужны, только чтобы файл было удобно смотреть руками.

### Открытые диапазоны, не номера строк

Лист «Финансы» содержит **две** таблицы (Долги и Кэшфлоу), а между блоками есть
заголовки и пустые строки. Поэтому ни один диапазон не зашит по номеру строки:
каждая таблица находится по строке заголовков, а её тело идёт до первой пустой
строки (`app/services/tables.py`). Новый долг вставляется **внутрь** своего
блока, а не в конец листа, так что таблица кэшфлоу просто сдвигается вниз и
остаётся целой.

## Экраны

| Экран | Что делает |
|---|---|
| Dashboard | Долг, вес (+дельта), конверсия отклик→оффер, streak чек-инов, остаток за неделю, лента последних 10 изменений, быстрые действия |

| Чек-ин | 3 тумблера + настроение 1–5, upsert по дате — второй строки за день не появится |

| Долги | Карточки с прогресс-баром выплаты; тап → правка «Осталось» |
| История | Лента по всем листам, фильтр по типу, удаление с подтверждением |

## Авторизация

Единственный механизм — подпись Telegram:

1. Mini App передаёт `initData` в заголовке `X-Telegram-Init-Data`.
2. Бэкенд считает HMAC-SHA256 с ключом `HMAC(“WebAppData”, bot_token)` и
   сравнивает с полем `hash`.
3. Проверяется свежесть `auth_date` (по умолчанию 24 часа).
4. `user.id` сверяется с `ALLOWED_TELEGRAM_ID`.

Всё, что не прошло — `403`. Логина и паролей нет и не нужно.

## Локальный запуск

Нужны Python 3.11+ и Node 20+.

```bash
cp .env.example .env        # заполнить BOT_TOKEN, ALLOWED_TELEGRAM_ID, SPREADSHEET_ID, GOOGLE_CREDENTIALS_JSON

# бэкенд
cd backend
python -m venv .venv && .venv/bin/pip install -r requirements.txt
set -a && source ../.env && set +a
.venv/bin/python -m uvicorn app.main:app --reload        # http://127.0.0.1:8000

# фронтенд (в другом терминале)
cd frontend
npm install
npm run dev                                              # http://127.0.0.1:5173
```

`npm run dev` проксирует `/api` на бэкенд. В обычном браузере Telegram SDK
отсутствует — приложение отрисуется, но API вернёт `403`, потому что подписать
`initData` может только Telegram. Для проверки живых данных открывай Mini App
из самого Telegram (например, через ngrok-туннель на 5173).

## Деплой на Railway

1. Создать сервис из этого репозитория. `nixpacks.toml` уже описывает сборку:
   ставит Python и Node, собирает фронтенд, запускает `backend/run.py`.
2. Прописать переменные из `.env.example` в Railway → Variables.
   `GOOGLE_CREDENTIALS_JSON` — весь JSON ключа одной строкой.
3. Включить публичный домен и положить его в `WEBAPP_URL`.
4. В @BotFather: `/setmenubutton` → тот же URL (бот и сам выставляет его при старте).

Healthcheck — `GET /health`.

### Доступ к таблице

Создать service account в Google Cloud, включить **Google Sheets API**, скачать
JSON-ключ и **поделиться таблицей с `client_email` из ключа** (права — Editor).
Без этого шага запросы вернут ошибку доступа.

## Что стоит знать при доработке

**id записи — это номер строки в таблице.** Для однопользовательского трекера
этого достаточно, и перед любой записью id проверяется на принадлежность своему
блоку, так что устаревший id не перезапишет чужую строку (вернётся `404`).
Но если две вкладки открыты одновременно и в одной строка удалена — id во второй
уже указывает на соседнюю запись. Для одного пользователя с телефона это не
проблема; при расширении понадобится отдельная колонка с id.

**Порядок в истории приблизительный.** В Sheets нет времени добавления строки,
поэтому лента сортируется по дате события, а при равных датах — по позиции
строки (новые строки дописываются вниз). Это ближайшее, что можно получить,
не заводя отдельную колонку с таймстампом.

**Частичное обновление.** `PATCH` пишет только переданные поля, по одной ячейке
(батчем в один запрос). Колонки, которых нет в Mini App, и формулы в соседних
ячейках остаются нетронутыми. `null` в запросе значит «не трогать»; чтобы
записать «нет» в привычках, шлётся `false`.

**Пустая таблица.** Если лист совсем пустой, бэкенд один раз запишет строку
заголовков. Непустой лист он не трогает никогда.
